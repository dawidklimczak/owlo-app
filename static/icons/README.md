# PWA Icons

Place the following PNG files here before deploying:

- `icon-192.png` — 192×192 px
- `icon-512.png` — 512×512 px (also used as maskable icon)

You can generate them from `../favicon.svg` using any image tool or a service like https://realfavicongenerator.net.

The background color is `#1a1a2e` and the icon uses the PulseFeed SVG logo.
